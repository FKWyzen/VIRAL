# VIRAL - Viral TikTok Clip Generator

Convert long-form videos into viral TikTok-ready clips automatically.

## Features
- 🎯 Automatic viral moment detection
- ✂️ Smart video clip extraction
- 🎨 Effects, music, and text enhancement
- 📱 TikTok optimization (1080x1920, 9:16)
- 🎬 Full-stack application (Backend + Frontend)

## Getting Started

See documentation in the respective directories:
- `/backend` - Node.js/Express API
- `/frontend` - React UI
